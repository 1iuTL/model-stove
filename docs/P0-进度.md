## 四、已定决策（不要重新讨论）

- **argv 逐字节不变**：安全收紧走代理层，不往 llama-server 命令行加 `--no-slots`。
- **端口动态**：从 8091 起找第一个空闲端口，只绑 `127.0.0.1`；失败不静默回绕。
- **数据目录优先级**：`MODEL_STOVE_HOME` > 便携（安装目录下 `data/`）> `app.getPath('userData')` > `%APPDATA%\Model Stove`。
- **配置优先级**（低→高）：内置默认 → 安装目录 `site.json` → 数据目录 `config.json` → 环境变量 → CLI 配置文件。
- **模型根**：环境变量 `MODEL_STOVE_MODELS` > 配置 `models.roots` > 自动建议（非系统盘最大空闲盘的 `Models/`），回落 `%USERPROFILE%\Models`。
- **设置 schema v2**：`version/apiKey/probe/lanMode/keepServerOnClose/lastModelId/lastPreset/accessMode`；
  `accessMode` 只允许 `local|lan|tunnel`，默认 `local`。
- **关窗默认保留 llama-server**（`keepServerOnClose: true`），托盘停止退出（后续 P4 接线）。
- 平台范围：Windows 10/11 + NVIDIA。不做 Linux/macOS/AMD。
