API KEY
设置后,llama-server 的所有接口都要带这个 Key。
聊天界面自己认识它 —— 手机上第一次打开会弹出输入框,填一次即存住。
注意:留空且开启局域网时,同网段任何人都能直接用你的模型。
局域网访问
手机扫码打开
  1. 在电脑上开移动热点,让手机连上它(校园网常隔离设备,热点最稳)
  2. 点左侧「启动」并等模型加载完 —— 没启动的话手机只会一直转圈
  3. 手机扫上面的码或手输地址
  4. 首次打开会要 API Key,填一次即可
